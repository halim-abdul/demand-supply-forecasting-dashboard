# Research notebooks

These notebooks form a progressive research track for the Göttingen supermarket demand/supply project. Run `python scripts/generate_demo_data.py` first, then proceed in numeric order. Each notebook is intentionally focused on one question so experiments remain reproducible and comparable.

01–07: data and exogenous signals  
08–10: forecasting and validation  
11–13: inventory decisions  
14–17: scenarios, hierarchy, ensembles, anomalies  
18–20: realtime simulation, monitoring, end-to-end system
